# Reconciliation Controls

- Transaction count equals source row count.
- Total dashboard spend equals source transaction spend.
- 2024 plus 2025 spend equals all-period spend.
- Compliant plus maverick spend equals total spend.
- On-contract plus off-contract spend equals total spend.
- Opportunity IDs in savings pipeline exist in opportunity register.
- Recommended scenario exists once per category.
- Realized savings cannot exceed implemented savings.
