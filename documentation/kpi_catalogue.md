# KPI Catalogue

| KPI | Definition |
|---|---|
| Total Spend | Sum of spend in INR |
| Addressable Spend | Spend included in an identified sourcing opportunity |
| Maverick Spend Rate | Maverick spend / total spend |
| Off-Contract Spend Rate | Off-contract spend / total spend |
| Top Supplier Share | Highest supplier spend / category spend |
| Supplier Concentration | Spend share held by leading suppliers |
| Expected Savings | Addressable spend × scenario savings rate |
| Risk-Adjusted Benefit | Expected savings × confidence × risk adjustment |
| Realization Rate | Realized savings / identified savings |
| Savings Leakage | Identified savings - realized savings |
| Supplier Risk Score | Configurable weighted supplier-risk indicator |
