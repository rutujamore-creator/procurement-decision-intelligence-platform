# Implementation Roadmap

## Phase 1: Trust the Data
Source reconciliation, supplier hierarchy, category taxonomy, contract mapping, FX rules.

## Phase 2: Identify Opportunities
Fragmentation, compliance recovery, price harmonization, sourcing pipeline.

## Phase 3: Evaluate Trade-offs
Savings, concentration, risk, quality, delivery, implementation complexity.

## Phase 4: Govern Delivery
Owners, approvals, stage gates, benefit validation, leakage reasons.

## Phase 5: Operationalize
Monthly CPO review, category-manager workbench, supplier-risk integration, adoption measurement.
